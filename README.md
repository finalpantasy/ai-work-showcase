# AI Strategy & Product Delivery

A focused portfolio of business strategy, AI-assisted product work, and reusable operating workflows.

My approach is to define the business problem, give AI useful context, direct implementation, and check the result against explicit acceptance criteria. Human judgment remains part of the workflow.

## Scope

This repository contains portfolio writing and original workflow templates. Development source, real account access, private conversations, and operational records are kept separately. Fictional examples are labeled throughout.

Tools used in the wider work include Claude Code, OpenAI Codex, and ChatGPT. Contributions include strategy, requirements, AI-assisted implementation direction, and verification; upstream and team contributions are credited in the project briefs.
